把望远镜
带到路边

第十四届的图像档案里，望远镜多次出现在校园广场：有人排队看月面，有人第一次靠近调焦机构，也有人在雨后的灯光下等待云隙。路边天文把观测从课程和远行带回日常。

一台镜子，就是一座临时天文台

“路边天文”目录保留26张现场照片，记录望远镜在校园公共空间的搭建、调试与排队观测。人物影像不进入公开页面；专题仅采用一张无人、无联系方式的器材环境照。

01 / SET UP

架设

三脚架、赤道仪与镜筒被带到广场，观测点随天象和天气临时形成。

02 / FOCUS

调焦

照片保存了器材操作与讲解的过程，也显示观测并非只发生在课堂里。

03 / SHARE

共享视野

在夜间公共空间排队观看，让一次个人观测变成面向路人的即时科普。

影像记录26张照片构成同一主题目录；多张文件名带有2018年10月25日至26日的时间线索。
