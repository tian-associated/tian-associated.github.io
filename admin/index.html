上传操作由私有 GitHub 仓库登录和权限保护。官网不保存密码或 Token，Word/PDF 原文件也不会复制到公开网站。

仅上传确定可以公开的科普与协会宣传资料，不要上传内部章程、成员隐私或未授权照片。
